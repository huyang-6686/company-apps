# 各应用最终规范发布与接入执行提示词

## 发布对象

各应用负责人、产品负责人、研发负责人、实施负责人和接口联调负责人。

## 正式通知

现发布与光工作中台五份正式规范及配套接口合同。请各应用将本消息及附件作为本应用后续建设、上架、接口开发、通知配置和联调验收的强制执行依据。

所有应用必须严格执行规范中的组织、租户、权限、应用归属、网盘、任务、通知和菜单边界。不得根据本应用习惯自行解释、缩减、替换或建立与规范冲突的本地规则。

## 必须一并发送的最终版文件

1. 《组织架构管理规范-20261019正式版》
2. 《应用搭建结构规范-20261019更新版正式版》
3. 《网盘映射管理与文件命名规范-20261019更新版正式版》
4. 《任务发布与管理规范-20261020正式版》
5. 《统一信息通知与应用消息通道规范-20261020正式版》
6. 《任务接口合同-20261020正式版》

8. 《五份规范一致性自检记录-20261020》

## 必须执行的统一边界

### 1. 组织和租户

- 使用与光工作中台统一组织架构和统一员工 ID。
- 应用不得另建第二套组织主数据。
- 双租户身份必须保留租户来源、登录入口和对应飞书 `user_id`。
- 跨租户协作不等于双租户主数据合并。
- 发送飞书消息时，必须按来源应用所属租户和目标员工在该租户的飞书账号路由。

### 2. 业务应用和数据

- 各应用独立负责自己的业务页面、业务状态和办理流程。
- 跨应用数据只能通过与光工作中台批准的接口合同交换。
- 禁止直接读取其他应用数据库。
- 应用内正式审批和业务执行仍留在来源应用或规范指定的飞书 OA 页面。

### 3. 任务

- 任务类型只有日常任务、经营任务、项目任务。
- 协作部门/协作人为选填字段，不单独建立“协作任务”类型。
- 支持向下发布和同级协作，不支持向上发布，不支持下属辐射。
- 接收人提交结果后由发布人验收；驳回原因必填。
- 任务附件按所属应用的网盘映射归档，工作台保存索引和权限日志。

### 4. 统一通知和飞书机器人

- 所有任务、轻审批、工作流节点、系统待办和异常事件必须进入与光统一通知中心。
- 每个接入应用必须提供本应用统一信息通知板块。
- 业务通知必须由来源应用自己的飞书机器人发送给对应租户本人。
- 不得使用与光工作台机器人代替来源应用发送业务通知。
- 员工点击机器人消息后，必须直接打开来源应用具体办理页面或来源应用通知详情页。
- 与光总通知板块只负责跨应用汇总、未读、待办理、逾期总览和统计，不复制来源应用办理流程。
- 通知失败时，应用内通知不能丢失；必须支持重试、失败回执和补偿查询。

## 各应用必须完成的接入事项

请逐项完成并提交证据：

- [ ] application_id、模块 ID、应用负责人和接口负责人已确认
- [ ] 应用可接收的任务类型和模块范围已确认
- [ ] 组织、应用、模块、项目和实体授权映射已完成
- [ ] 统一员工 ID 与本应用人员关系已核验
- [ ] 对应租户的飞书机器人已配置，不与其他应用共用机器人身份
- [ ] 机器人发送账号与目标员工 `target_feishu_user_id` 路由已验证
- [ ] 本应用信息通知板块已提供：未读、待办理、已处理、逾期、全部通知
- [ ] 任务、轻审批、工作流节点和异常事件接口已实现
- [ ] `notification.created`、`notification.updated`、`notification.expired` 事件已接收
- [ ] 已读、待办理、已处理和机器人发送结果回传接口已实现
- [ ] 每类通知都有可用的来源应用具体办理深链
- [ ] 深链打开时会重新执行本应用权限校验
- [ ] 网盘映射目录已确认，附件不进入未经批准的本地对象存储
- [ ] 请求签名、幂等键、事件去重和失败补偿已实现
- [ ] 测试账号和联调环境已准备
- [ ] 审计日志已覆盖创建、权限判定、发送、重试、已读、打开、办理和失败

## 强制验收场景

各应用必须至少完成以下场景，并提交测试结果：

1. 与光发布任务，应用通知板块出现待办理通知。
2. 来源应用自己的飞书机器人向对应租户本人发送消息。
3. 点击机器人消息直接进入来源应用具体办理页。
4. 应用内完成接收、办理、反馈和验收，统一通知状态同步。
5. 轻审批和工作流节点通知可以进入应用通知板块和与光总通知。
6. 截止、逾期、自动转派和逾期总览状态正确。
7. 多租户同一员工按来源应用租户收到正确账号的消息。
8. 无权限人员不能看到通知详情，深链打开时不能越权。
9. 重复事件不会重复生成通知或重复办理。
10. 机器人发送失败时应用内通知仍保留，重试和补偿可查询。
11. 附件权限、网盘链接和下载日志符合网盘规范。
12. 离职或账号失效后停止新消息投递，历史记录按规则保留。

## 禁止事项

- 禁止把来源应用业务通知全部改由与光工作台机器人发送。
- 禁止把所有业务办理页面复制到与光工作台。
- 禁止让机器人消息只跳转到与光总通知而没有来源应用办理入口。
- 禁止绕过统一员工 ID、租户路由和应用权限校验。
- 禁止直接读写其他应用数据库。
- 禁止将任务附件、审批附件或业务正式文件存入未批准的对象存储。
- 禁止静默修改规范；发现冲突必须先提交问题、影响范围和建议方案。
