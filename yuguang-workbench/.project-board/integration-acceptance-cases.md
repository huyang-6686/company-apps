# 与光工作中台应用接入验收清单

更新时间：2026-10-20

本清单来自 2026-10-20 正式发布通知的强制验收场景。每个接入应用必须逐项提供测试记录、事件 ID、通知 ID、操作者、租户和结果证据；未提供证据时状态保持“待联调”。不得把凭据、访问令牌或附件原文写入清单。

| 编号 | 验收场景 | 必须验证的结果 | 当前状态 | 证据/事件 ID |
|---|---|---|---|---|
| AC-01 | 与光发布任务后应用通知板块出现待办理 | 来源应用通知板块生成对应待办理记录，来源应用和模块正确 | 待联调 | 待补充 |
| AC-02 | 来源应用机器人发送消息 | 使用来源应用所属租户自己的机器人发送给对应本人账号 | 待联调 | 待补充 |
| AC-03 | 点击机器人消息进入办理页 | 深链直接打开来源应用具体办理页面或通知详情页 | 待联调 | 待补充 |
| AC-04 | 接收、办理、反馈和验收闭环 | 应用内操作和与光通知状态同步，驳回原因必填 | 待联调 | 待补充 |
| AC-05 | 轻审批和工作流节点入通知 | 应用通知板块和与光总通知均有汇总，办理仍在来源应用 | 待联调 | 待补充 |
| AC-06 | 截止、逾期、自动转派和逾期总览 | 截止提醒、逾期提醒、自动转派和总览状态符合规范 | 待联调 | 待补充 |
| AC-07 | 多租户员工投递 | 按来源应用所属租户投递到正确的本人飞书账号 | 待联调 | 待补充 |
| AC-08 | 无权限访问拦截 | 无权限人员不能查看通知详情或打开来源业务页面 | 待联调 | 待补充 |
| AC-09 | 重复事件去重 | 重复事件不重复生成通知，幂等键和去重日志可查 | 待联调 | 待补充 |
| AC-10 | 机器人发送失败补偿 | 应用内通知保留，支持重试、失败回执和补偿查询 | 待联调 | 待补充 |
| AC-11 | 附件与网盘审计 | 附件权限、网盘链接、下载日志和审计记录符合规范 | 待联调 | 待补充 |
| AC-12 | 离职或账号失效 | 停止新消息投递，历史通知和业务记录按规范保留 | 待联调 | 待补充 |

## 通过门槛

- 12 个场景全部完成，且每个场景有可复核证据。
- 任务接口、通知事件、权限矩阵、网盘映射和审计日志核验均通过。
- 应用负责人和与光负责人共同确认后，才可把生产许可从“禁止”改为“申请中”或“已批准”。
- 当前没有任何应用达到上述条件，生产许可统一保持“禁止”。
