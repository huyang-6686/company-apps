## 二、数据共享主干（跨页面联动关系）

全店围绕以下主数据链联动，改动一处会牵动多处：

| 主数据 | 源头页面（产生） | 被哪些页面引用（共享） | 关联键 / 机制 |
|---|---|---|---|
| 物料标准价 `material_standards` | 核算标准（人工维护）；统一录入回写"累计采购额" | SOP 配方算成本、产品目录、定价毛利、盘点差异、Dashboard | 物料编号 / 名称；标准价变动 → 成本重算 |
| 产品 / 系列 / 配方 / 杯型 `sop_products / sop_series / sop_recipes / sop_cups` | 产品目录（唯一源） | 学习中心 SOP 学习卡、定价、销量、中枢日报 | 产品编号 `product_code`；A主料精确/B随餐耗材估算/C期间费用三档 |
| 杯型规格 `cup_spec` + `cup_product_binding` | 规则中心（杯型规格） | 产品目录按杯区分配方、SOP 详情 | 杯型编号；停用前校验是否仍绑定在售产品 |
| 供应商 `suppliers`（含售后联系人） | 供应商管理；统一录入自动建档 | 统一录入匹配、运营台账展示 | 供应商编号 / 名称 |
| 票据 `bill_records / bill_items` | 统一录入（AI OCR） | 分流到采购/费用/资产/人员台账 | 票据号；统一录入订单 `union_orders/items` |
| 人员 / 组织 `feishu_org_person` | 组织与人员（飞书同步） | 日清排班、人员成本、接待/客诉经办人、成本归属、各人员选择器 | 飞书 user_id（含"同步来源"标记：轻立方/与光） |
| 排班 / 日清任务 `daily_schedule / daily_close_task` | 管理报表排班 / 日清日结 | 管理报表对账、Dashboard 当日待办 | 日期 + 班次（早/午/晚）+ 负责人 user_id |
| 日销售 `daily_sales / sales_volume` | 收入台账、日清提交 | Dashboard、管理报表、周/月结、定价（销量×成本）、中枢日报 | 日期；分产品销量按 product_code |
| 学习 / 档案文件 `learning_document / archive_documents` | 学习中心、档案中心 | 飞书网盘按目录归档；素材/报表/签字件复用 | 文件实体在飞书网盘，表内只存元数据 + 云盘 token |
| 角色权限 `rbac_role_matrix` | 权限与角色 | 菜单过滤 + 路由守卫 + 页面内操作 | 角色码 × 模块码（全局 RbacGuard） |
| 中枢任务 `task_executions`、消息 `council_messages` | 中枢接入 / 任务执行台账 / 军机处群 | 收令→回执→执行→回传；Dashboard 中枢数据 | 诏令编号 `edict_code` 幂等去重 |

> 注：产品数据当前存在 `sop_*`（主口径）与 `products / product_recipes`（含历史 `recipes`）两套表，需在落地时收敛为一套。

## 十一、复盘结论

### 已实现且数据贯通的链路
1. **统一录入（票据 AI OCR）→ 采购/资产/费用/人员/供应商分流 → 各台账只读 + 物料累计采购额回写**，成本数据一个写口。
2. **物料标准价 + 产品目录配方（A/B/C 三档）→ 产品成本/毛利 70% 红线 → 学习中心 SOP 卡只读复用 + AI 定价建议**，产品数据唯一源。
3. **日清排班/认领/提交（含照片、收款方式）→ 管理报表日/周/月结 + 接待/活动/客诉/巡店/设备/归档 → Dashboard 与中枢日报**。
4. **杯型规格（规则中心）→ 产品目录按杯区分配方**，停用有冲突校验。
5. **飞书网盘凭据 → 档案/学习/附件/签字件/导出归档**统一底座。
6. **飞书长连接（群 @收令）→ 任务执行台账（回执/解析/执行/回传）→ 军机处**，30 分钟轮询兜底。
7. **RBAC 矩阵 → 菜单/路由/页面三级守卫**；双租户飞书组织同步（轻立方全员、与光仅望向山）。

### 未完成 / 风险点（如实标注）
- ⚠️ **产品定价独立页未挂载**：`PricingPage.tsx` 无路由无菜单；定价能力暂在产品目录内，需决定补挂还是永久并入。
- ⚠️ **角色为 6 个，定稿 8 角色未落地**：行政人事未拆、无"经营管理"；上架授权前需开发并迁移矩阵。
- ⚠️ **产品数据两套表并存**（`sop_*` 与 `products/product_recipes`、历史 `recipes`），需收敛主口径。
- ⚠️ **收入台账 Excel 导入、美团/外卖平台同步、导出表格为"开发中"**，当前仅手动登记。
- ⚠️ **素材设计为纯占位**，待对接工部·绘事署；盘点损耗模块未闭环；生态"登记收支/协议下载"待接入。
- ⚠️ **飞书收令链路尚未真机验收**（长连接事件/权限/版本已在飞书侧正常，群 @触发执行的端到端待跑通 DIAG-TEST）。
- ⚠️ **数据权限全在应用层**（无数据库行级安全 RLS），店员"仅看自己"、双租户数据隔离需重点核对。
- ⚠️ `APP_SECRET_KEY` 为弱默认值，上架前必须注入 32 位随机强密钥；敏感凭据（飞书 App Secret / 中枢 token）加密存储、不入源码。
