# 星窗工作台首期方案（待审阅）

状态：草案 v1，待创始人确认后进入分步开发计划
日期：2026-10-19

## 1. 首期展示范围

- 定位：星窗工作台为纯对外展示应用，不承载 OA 数据，不做内部业务处理。
- 首期内容类型（待系统扫描确认后逐项开启）：项目方案、项目案例、设计方案、设计成果、公开知识文章、品牌展示物料。
- 经营管理暂不开放；人力、行政、财务、法务默认禁止共享。
- 来源应用：与光工作中台（项目管理）、灯塔知识库、品牌生产中枢、望向山经营中台、镇安生态产业协会管理中台；后续应用按统一接入规范扩展。
- 应用接入不等于数据共享：只有白名单内的内容类型和字段可进入星窗。

## 2. 权限与角色

- 组织与角色：由与光工作中台同步，星窗只执行；部门取一级部门。
- 系统策略配置页：仅创始人可修改（接入应用开关、内容类型白名单、字段白名单；白名单支持部门默认值，只能比全局默认更严格；变更留痕）。
- 分享发起：一级部门负责人、部门经办人；入口受应用开关、内容类型白名单、用户角色共同控制；无权限或被关闭时业务页右上角不显示分享按钮。
- 字段选择：分享配置页只渲染白名单内字段，禁止字段不可编辑。
- 审核分派（按与光角色层级）：人力行政财务法务、灯塔知识库=创始人；项目、经营、镇安生态产业协会=连媚；望向山=夏倩；品牌=王辉。
- 外部访问：免登或授权密码链接；内部人员按角色权限访问。

## 3. 内容与发布模型

- 内容版本化：每条内容独立版本，公开字段、访问范围、署名按版本配置。
- 生命周期：草稿 → 待审核 → 已发布 → 已下线/已到期 → 归档；删除留痕。
- 访问方式（首期仅三种）：公开链接、密码链接、仅内部预览。
- 有效期：默认长期；限时内容到期自动下线，重新审核后才能再发布。
- 撤回/下线：立即生效，公开链接与缓存即时失效，页面和接口直接返回下线提示。
- 留痕要求：发布、撤回、下线、删除均记录操作人、时间、版本、原因、数据来源。

## 4. 数据流与接口边界

- 内部应用 → 星窗：通过受控提交接口，只传白名单字段；内部 ID、组织关系、客户信息、内部链接不传入公网。
- 星窗 → 公网：独立公开读取接口；不复用内部管理接口。
- 五段归属路径（来源应用/业务大类/模块/事项/科目）仅用于内部检索、权限与追溯，不自动渲染到公网页面。
- 模型调用统一走与光工作中台总接口。
- 回执合同：提交接口返回提交结果、星窗内容编号、版本号、当前状态、拒绝原因、校验错误位置；由系统扫描后按内容类型产出。
- 公开字段与回执合同：待现有应用开发完成后由系统扫描提供建议，默认拒绝并关闭不必要项，创始人确认开启。

## 5. 页面结构（首期）

对外（含手机端响应式）：首页、案例列表页、案例详情页、密码访问页、反馈入口、下线提示页。
内部（按与光权限）：内容管理、审核工作台（按应用分派）、系统策略配置页（仅创始人）、归档记录（按既定网盘映射）。
菜单遵守 1–4 级规范；内部五段路径作为内容归属与筛选，不作为第 5 级菜单。

## 6. 安全与合规

- 不接入飞书 OA；星窗不擅自注册飞书应用。
- 公网接口：HTTPS、鉴权（免登/密码）、限流、访问日志、错误处理、敏感信息过滤。
- 密码链接：密码哈希存储，可撤销重置。
- 缓存：下线即失效；公开页缓存带短 TTL 并支持下线主动清除。

## 7. 部署与测试

- 部署：独立公网部署，与内部应用物理隔离；星窗只通过受控接口接收数据。
- 测试方案：页面（含手机端）、接口（提交/回执/公开读取/下线失效）、安全（越权、白名单绕过、限流）、发布流程（提交→审核→发布→撤回→归档全链路）。

## 8. 首期验证路径

先选一个内容类型（建议：项目案例）跑通完整闭环：来源应用分享 → 白名单校验 → 提交 → 审核（连媚）→ 发布（公开/密码链接）→ 外部访问（手机端）→ 反馈收集 → 撤回立即失效 → 归档。验证通过后再扩展其他内容类型与应用。

## 9. 待办与依赖

- 现有应用开发完成后：系统扫描产出公开字段建议与回执合同，创始人确认。
- 规范文件标题含草稿但正文声明 v3 正式版：命名一致性待确认。
- 反馈入口的具体形态（表单字段、通知渠道）待首期实现时细化。
