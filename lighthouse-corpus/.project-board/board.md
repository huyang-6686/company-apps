## 已确认决策

- 重建落点选择全新独立应用；旧灯塔应用仅作为历史证据和过渡期参照，不作为新系统代码基础
- 灯塔归口轻立方租户工具层；跨租户数据仅经工作台批准通道接入
- 组织架构以飞书通讯录为唯一来源，经工作台同步；灯塔不维护第二份组织主数据
- 角色权限依工作台下发标准；灯塔不自建权限体系或定义角色
- 整个体系不参与飞书 OA（2026-10-18 创始人确认，替代此前"正式审批统一走飞书 OA"决策）；迁移/删除由创始人按清单自行执行，灯塔只输出清单并记录操作结果反馈
- 三库定位明确：飞书=资料库（方案/文档/合同/文件/logo/小图标，不存视频正文）；本地=素材库（运行态和临时素材，可能后续删除）；百度网盘=成果库（成品视频/素材，对外分享用共享链接）
- 知识节点导航沿用旧应用分类树结构，展示层按权限过滤（创始人全量）；扫描后系统重新梳理分类层级和分支，输出清单供创始人确认
- 所有模型调用统一经工作台总接口；模型通道、计费与限额由工作台管理
- 跨租户群推送仅经工作台批准的消息路由接口；未获批时暂停与光租户推送
- 既有节点库先冻结基线并按新 schema 批量导入，六清单作为后续扫描基线
- 阶段 0 先验证中文全文检索扩展与分词；失败时降级为 `pg_trgm` 或应用层分词 + `tsvector`
- 首期全部来源先扫描建节点，正文解析按来源优先级、目录白名单、时间范围和人工置顶内容控制
- 分享、扫描、解析、归档和删除采用统一状态机，包含超时、重试、死信和告警
- 检索与问答严格服务端先鉴权过滤，再召回、排序和组装 LLM 上下文；证据不足时拒答
- 采用公开、内部、受限、私属四级敏感分级；标题、摘要、正文、附件、引用和导出统一执行字段级权限矩阵，创始人调整必须留痕
- 建立每日数据库备份、归档文件校验、RPO/RTO 目标和季度恢复演练
- 每个阶段设置交付物、可验证退出准则和回滚点；新旧系统双轨运行，连续稳定后切换旧推送和旧扫描
- 飞书云盘现有视频仅在本次扫描阶段处理并迁移至百度网盘；抖音等外链按知识分享提炼要点存档或应用；百度网盘作为素材与案例库，仅保存可鉴权链接，不解析视频
- 情报作为独立节点类型保存并经过来源校验；来源不明或待核实内容默认仅创始人可见
- 所有大模型调用统一经工作台总接口；灯塔不直连模型服务商
- 审计日志采用追加写入和防篡改存储，明确保留期限、查看权限和导出权限
- 员工贡献按相关性、时效性、重复性和来源可追溯性等维度评估，由创始人确认；不合格内容退回并保留原因和申诉记录
- 员工贡献提交时记录署名与组织使用许可；离职后保留已归档组织知识，依法处理个人信息删除请求；外部资料仅保存来源、链接和提炼要点
- 灯塔知识库按应用级归属处理，不纳入轻立方业务组织路径；如产生正式归档，唯一目标为 `租户轻立方 / 个人网盘 / 2. 灯塔知识库`
- 员工登录与权限由与光工作中台按“组织架构 + 角色”划分并下发；灯塔只消费和执行结果，不建立第二套组织或角色体系
- 单一灯塔应用允许轻立方与与光两个租户安装；两边人员登录后统一到与光工作中台核验已同步的人员、组织和角色，灯塔不建立租户内第二套授权映射
