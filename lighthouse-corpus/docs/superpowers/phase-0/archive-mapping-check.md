# 网盘归档映射核验

## 依据

- 《网盘映射管理与文件命名规范-20261018更新版正式版.md》v3，2026-10-18。
- 《应用搭建结构规范-20261018正式版.md》v1，2026-10-18。
- 项目设计基线：`docs/superpowers/specs/2026-10-17-lighthouse-knowledge-base-design.md`。

本报告核对规范文本和设计约束，不代表已连接或验证真实网盘。实际云盘 ID、授权范围、API、同步延迟、删除回收行为和写权限均为 `unknown`；未完成阶段 0 授权核验前不得访问或写入网盘。

## 核验结果

| 检查项 | 规范要求 | 设计状态 | 实际连接状态 |
|---|---|---|---|
| 唯一归口 | 租户轻立方 / 个人网盘 / `2. 灯塔知识库` | 已纳入 | unknown |
| 顶层目录 | 不在个人网盘下自行新建顶层目录 | 已纳入 | unknown |
| 目录编号 | 文件夹使用名称 + 固定数字前缀；不因日期改变编号 | 已纳入 | 尚无网盘清单可验证 |
| 模块内部结构 | 每个模块包含固定 `0.〔模块名〕制度操作模板历史版本汇总`；事项文件夹从 1 起编号 | 已纳入 | 尚无模块目录可验证 |
| 生效制度 | 平铺在模块根目录 | 已纳入 | 尚无文件清单可验证 |
| 失效制度 | 自动移入 0 号目录并标注“已失效+日期” | 已纳入 | 自动化能力 unknown |
| 云盘删除 | 删除同步至应用回收站并保留 30 天 | 已纳入设计；不设置应用内审批或额外硬删除规则 | 同步和回收站 API unknown |
| 百度网盘链接 | 每月人工巡检；失效时更新节点状态并告警，不自动删除或重新解析 | 已纳入设计 | 链接校验能力和巡检责任人 unknown |
| 文件命名 | 页面生成/导出文件使用事项名称 + 版本号 + 日期；管理制度保留上传原名；一律不带公司名称 | 已纳入 | 尚无生成器或样例可运行核验 |
| 菜单层级 | 1 级仅展开/折叠；2 级模块是权限分组；3 级事项承载状态留痕；4 级科目为最小页面；禁止 5 级 | 设计约束已纳入 | 实际菜单尚未实现 |
| 未定稿子菜单 | 不自行确定待业务大类梳理的 2/3 级子目录 | 设计约束已纳入 | 后续需按规则更新草稿 |
| 处置决定 | 灯塔只输出迁移/删除/保留清单；创始人自行执行并反馈结果 | 已纳入 | 执行反馈入口 unknown |

## 冲突及处置

早期设计曾描述“应用内创始人二次确认硬删除”和“正式决定经飞书 OA 分流”。2026-10-18 收尾更新已覆盖这些表述：灯塔只生成清单；创始人自行执行迁移、删除或保留，并反馈成功/失败/跳过及失败原因。云盘删除同步至应用回收站保留 30 天的连接器语义仍须实测。

## 尚待验证

- 工作台批准的数据源和网盘映射接口契约。
- 轻立方个人网盘和 `2. 灯塔知识库` 的真实云盘 ID、目录清单及鉴权能力。
- 目录创建/移动/重命名、回收站、30 天保留和恢复 API 的实际语义。
- 归档批次的幂等、源 ID 重绑、哈希对账、审计字段和失败补偿能力。
- 实际灯塔菜单与 2/3 级待定条目的逐项映射；在业务大类梳理确认前保持未定稿。
