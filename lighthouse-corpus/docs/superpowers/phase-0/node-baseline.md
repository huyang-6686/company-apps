## 导入规则

- 幂等键：source_id + source_file_id
- 分批：每批 5000 条，失败批次进入死信
- 抽样核对：至少 200 条，核对标题、原路径、来源、时间和权限范围
- 对账：逐来源记录源清单、导入数、跳过数、失败数和差异原因
- 回滚：按批次撤销本批次导入并恢复导入前快照；具体执行须经批准流程，不得静默丢弃数据
- 版本：节点主键保持稳定，内容、摘要和权限快照进入 node_versions；软删除使用 deleted_at
