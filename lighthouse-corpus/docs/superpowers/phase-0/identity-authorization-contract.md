# 身份、组织与授权契约

## 已确认边界

- 灯塔是轻立方租户下的工具层应用。
- 飞书通讯录是组织架构唯一来源，由与光工作中台同步后再向灯塔下发；灯塔不维护第二份组织主数据。
- 业务角色和权限只使用工作台下发标准；灯塔不定义角色或权限，也不建立跨租户身份授权映射。
- 灯塔仅接收工作台批准分流的数据；迁移、删除和保留由创始人按清单自行执行，灯塔只接收执行结果反馈。
- 无法证明请求符合有效工作台授权标准时拒绝访问，并记录原因。不得设置本地管理员、白名单、恢复口令或其他授权旁路。

## 历史接口材料边界

`historical documents/06-数据库与接口（已补API契约）.md` 描述的是旧灯塔应用接口，并引用旧应用直接连接中台的实现材料；它不是新灯塔的工作台批准接口契约，也不提供当前授权、组织和执行反馈的批准字段及 SLA。该材料只作为历史证据，不能据此连接旧服务、复用旧凭据或推定新接口行为。现行工作台契约状态仍为 `unknown`。
