# 工作台权限标准执行矩阵

本表说明灯塔必须执行的内容字段处理边界，不创建本地角色，也不替代工作台权限标准。每次访问的最终允许/拒绝结果必须来自有效的工作台下发标准；本表中的“默认处理”不能单独作为放行依据。

| 内容级别 | 标题/摘要 | 正文/附件 | 引用/导出 | 灯塔处理要求 |
|---|---|---|---|---|
| 公开 | 仍须经工作台授权判定 | 仍须经工作台授权判定 | 引用回源复核；导出经授权并留痕 | 不因“公开”标签绕过授权 |
| 内部 | 仍须经工作台授权判定 | 仍须经工作台授权判定 | 引用回源复核；导出经授权并留痕 | 不在应用内映射员工角色 |
| 受限 | 仍须经工作台授权判定 | 仍须经工作台授权判定 | 引用回源复核；按下发标准处理导出 | 未获得字段级许可时拒绝或隐藏 |
| 私属 | 默认不向未获授权请求披露 | 默认不向未获授权请求披露 | 默认不披露 | 未获得明确有效授权时拒绝并留痕 |
| 未迁移/来源待核验 | 默认不披露 | 默认不披露 | 默认不披露 | 保持私属保护，不因模型生成摘要而放宽 |

执行要求：

1. 服务端先完成工作台授权判断，再进行检索、召回、排序或模型上下文组装。
2. 标题、摘要、正文、附件、引用和导出使用同一授权结果；引用回源时重新判断当前授权。
3. 大模型只能通过工作台总接口接收已获准的最小必要内容；契约未验证前不发起调用。
4. 本地内容级别仅用于处理与保护，不构成角色、授权标准或权限旁路。
5. 当前状态：design；实际角色/权限映射以待验证的工作台契约为准。
