# 网盘映射与归档测试用例

以下用例是阶段 0 的设计级测试输入，当前没有应用代码或获批网盘测试环境，因此尚未执行。所有写操作只能在获批隔离测试空间执行；不得在生产网盘中试写。

| ID | 场景 | 输入/操作 | 预期结果 | 当前状态 |
|---|---|---|---|---|
| ARC-001 | 唯一归口 | 生成任意灯塔归档目标 | 目标严格为轻立方个人网盘 / `2. 灯塔知识库`；其他租户、企业盘和中台盘目标被拒绝 | blocked: API unknown |
| ARC-002 | 禁止新顶层目录 | 请求创建灯塔归档根 | 只复用指定映射；不在个人网盘根新建目录 | blocked: API unknown |
| ARC-003 | 固定数字前缀 | 创建已确认模块和事项文件夹 | 模块及事项使用规范规定的固定编号；重试或日期变化不得改号 | blocked: API unknown |
| ARC-004 | 0 号制度历史目录 | 初始化模块 | 每个模块存在且仅有规范名称的 `0.〔模块名〕制度操作模板历史版本汇总` 目录 | blocked: API unknown |
| ARC-005 | 生效制度平铺 | 归档一份生效制度 | 文件位于模块根目录，不进入事项子目录或 0 号目录 | blocked: API unknown |
| ARC-006 | 制度失效迁移 | 将制度标为失效并给定日期 | 文件移至 0 号目录，保留上传原始名称并追加“已失效+日期”标记；操作可审计 | blocked: API unknown |
| ARC-007 | 生成/导出文件命名 | 生成事项报告 | 文件名由事项名称、版本号、日期组成，不含公司名称 | blocked: generator not implemented |
| ARC-008 | 创始人执行结果反馈 | 输入清单项的成功、失败、跳过及失败原因 | 仅记录结果和审计，不触发应用内审批；失败项可供下次重试 | blocked: feedback contract unknown |
| ARC-009 | 云盘删除同步 | 收到云盘删除事件 | 应用同步删除并进入回收站，保留 30 天；事件、路径、结果留痕 | blocked: API unknown |
| ARC-010 | 30 天保留边界 | 核对删除后 30 天内外状态 | 30 天内可验证仍在应用回收站；期满后的清理/恢复语义只按正式接口契约验证，不猜测 | blocked: API unknown |
| ARC-011 | 文件移动/重命名重绑 | 同一来源 ID 与源文件 ID 的文件更换路径 | 绑定原知识节点，不重复建节点；保留原路径快照，哈希变化进入核验/人工处理 | blocked: source contract unknown |
| ARC-012 | 批次幂等与对账 | 对同一归档批次重复提交 | 不重复落盘；重复项和文件数、哈希、路径差异进入对账报告 | blocked: API unknown |
| ARC-013 | 菜单层级边界 | 校验菜单树 | 最深 4 级；1 级只展开/折叠；2 级模块作权限分组；3 级事项带状态/留痕；4 级科目最小化 | pending: menu not implemented |
| ARC-014 | 未定稿子菜单变更 | 发现待梳理业务大类下新增/变更的 2/3 级条目 | 不自行定稿；基于当前正式版 +1 生成带日期、“草稿”和“待审核”的新规则草稿；不覆盖/发布旧版 | pending: no change observed |
| ARC-015 | 百度网盘链接月检 | 执行月度可鉴权链接巡检并注入失效链接 | 更新节点状态并告警；不自动删除节点或重新解析视频 | blocked: connector and owner unknown |

## 执行约束

- 取得工作台及网盘连接器书面契约和隔离测试空间后才可运行 ARC-001 至 ARC-012。
- ARC-013 在菜单实现后运行；当前只能检查设计约束。
- ARC-014 仅在实际发现对应菜单变化后触发；本文件本身不是新版规则草稿，也不修改正式规范。
- 每次执行保存脱敏请求/响应摘要、时间和 SHA-256；禁止保存凭据或真实业务文件。
