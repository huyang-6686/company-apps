# 工作台授权测试用例

这些为阶段 0 契约测试设计。当前没有新灯塔应用代码或工作台批准测试接口，所有用例均未运行。取得契约前不得虚构字段、有效期、缓存、重试或错误码；测试输入应由批准契约定义。

| ID | 用例 | 契约输入 | 预期行为 | 状态 |
|---|---|---|---|---|
| AUTH-001 | 已批准来源且请求获准 | 契约认可的身份、来源和字段范围 | 服务端允许契约明确授权的字段；审计保存判定引用 | blocked: contract unknown |
| AUTH-002 | 请求被工作台拒绝 | 工作台拒绝判定 | 不返回标题、摘要、正文、附件或模型替代内容；记录拒绝审计 | blocked: contract unknown |
| AUTH-003 | 来源未获批准 | 来源 ID 不在批准来源集合 | 不连接、不扫描、不导入该来源；生成可审计拒绝 | blocked: source set unknown |
| AUTH-004 | 字段范围不足 | 工作台只授权请求中的部分字段 | 仅按契约返回获准字段；其余字段不进入检索摘要或模型上下文 | blocked: contract unknown |
| AUTH-005 | 授权状态缺失或过期 | 由工作台契约标记无效的授权状态 | 拒绝无法证明有权的请求；不自创 TTL 或本地恢复口令 | blocked: contract unknown |
| AUTH-006 | 工作台不可用 | 测试代理返回契约定义的不可用错误 | 拒绝无法证明有权的请求，记录错误分类，不使用本地权限旁路 | blocked: contract unknown |
| AUTH-007 | 引用回源复核 | 先前可见的节点现已被工作台拒绝 | 再次鉴权失败后隐藏引用和正文，不复用旧授权快照 | blocked: contract unknown |
| AUTH-008 | 导出权限不足 | 工作台未授权导出字段或资源 | 拒绝导出并审计；应用不自建角色覆盖判定 | blocked: contract unknown |
| AUTH-009 | 创始人执行结果反馈 | 清单项的成功、失败、跳过及失败原因 | 灯塔记录反馈和审计，不代替创始人执行或创建审批流程 | blocked: feedback contract unknown |
| AUTH-010 | 反馈字段缺失或无效 | 缺少清单项、结果或失败原因 | 拒绝写入不完整反馈，记录拒绝/告警 | blocked: feedback contract unknown |

## 执行条件

- 由工作台责任方提供当前批准接口契约、版本和隔离测试入口。
- 只在隔离环境使用合成身份和脱敏数据；不得用旧应用密钥或生产身份试探。
- 测试报告记录契约版本、请求关联 ID、预期与实际结果；敏感值一律脱敏。
