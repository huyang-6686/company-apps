# 备份与恢复运行手册

## 目标

- RPO：不超过 15 分钟
- RTO：不超过 4 小时
- 每日数据库备份，WAL 连续归档
- 归档文件单独校验，备份密钥与数据分离

## 执行步骤

1. 在隔离环境确认 PostgreSQL 版本、pg_dump 和 WAL 能力。
2. 执行加密 pg_dump，记录文件大小、SHA-256 和完成时间。
3. 校验归档文件与数据库清单的数量、哈希抽样和版本。
4. 在隔离环境恢复数据库和归档文件，执行节点计数、权限矩阵和审计追加写入检查。
5. 记录实际恢复耗时；每季度重复一次。

当前 PostgreSQL 托管环境、WAL 权限、对象存储和恢复演练结果均为 unknown，不得宣称 RPO/RTO 已达标。
