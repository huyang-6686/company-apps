# 镇安县生态产业协会管理中台 — 需求澄清记录

阶段：2. 需求澄清（2026-10-18，2026-10-19 增补Harness复评条件标注）

规范基线：《网盘映射管理与文件命名规范》v3 正式版（2026-10-18）、《应用搭建结构规范》v1 正式版（2026-10-18）为唯一正式依据。镇安归口租户轻立方，网盘路径"中台网盘/3. 业务部/1. 项目部/2. 镇安生态产业协会管理中台"。

## 1. 登录与账号体系

- 统一登录页：同一入口自动识别账号类型，飞书用户跳转飞书授权，补充账号走密码登录。
- 非飞书租户补充账号由轻立方租户统一发放，与飞书账号等效。
- 补充账号生命周期：与飞书组织架构同步联动，挂轻立方"补充人员"虚拟部门；账号自带有效期，到期自动回收；延期由管理员续期。
- 补充账号权限按类型分级：长期协作者给部门级权限，临时访客只给指定模块权限，两级各自预设。

## 2. 组织架构

- 飞书同步按需进行，只同步与协会业务相关的部门和成员。
- 协会专属部门树暂不指定，待拿到轻立方组织架构后再定。

## 3. OA 对接（钉钉）

- OA 试点与外部表单分开：支出审批继续使用甲方钉钉并回流；会员单位不进入飞书/钉钉，入会资料通过外部信息录入表单链接收集，进入协会内部待审核/待补正处理。
- 复评增补：M2 “入会审批（OA试点）”这一表述已被 2026-10-19 决策取代；入会不是 OA 审批，实现按外部表单收集 + 内部资料核验处理。
- 会员外部表单访问方式：公开链接 + 一次性/有效期控制；会员无需账号，提交后生成编号并支持补正。
- 飞书是运营团队办公软件，是否承载用印等内部 OA 待确认；不把飞书 OA 当作已确定的入会审批入口。
- 回流处理：钉钉用款审批通过后自动生成财务流水草稿，人工确认后生效；会员表单提交后生成会员申请记录/档案草稿，按协会内部处理规则确认生效。

## 4. 核心模块优先级

会员管理 → 财务管理 → 档案管理 → 项目管理 → 人事/迎检。

## 5. 会员管理（第一版）

范围：最小可用三件套 — M1 会费标准表 + M2 入会审批（OA 试点）+ M5 会费收缴与欠费。

### 5.1 会费标准表（M1）

- 结构：身份档位 × 年度 × 金额 × 生效日期。
- 拆分会员类型（单位会员/理事单位/副会长单位/会长单位）与任职身份（会长/副会长/秘书长/理事/普通）两个字段，会费挂任职身份。
- 初始五档（章程第八条）：单位会员 500 / 理事单位 1,000 / 秘书长、理事 2,000 / 副会长 5,000 / 会长 10,000。
- 已知事项：理事单位档位（1000 vs 2000）需理事会书面确认并写备注；会费档次一般不超过 4 级是收费政策口径，与菜单 1-4 级无关；当前 5 档合规风险需留意；标准制定/修改需会员大会无记名表决通过并有记录，标准表需支持存放表决记录附件。

### 5.2 会费收缴与欠费（M5 / P02 / P03）

- 应收账单：每年初按标准表自动生成全体在册会员应收账单（单位+年度唯一），已退出会员不计当年应收。
- 缴费登记：秘书处人工登记，支持"部分缴清/已缴清"，缴费后回写会员状态（欠费→正常）。
- 欠费提醒（P03）：实时派生视图（应缴−实缴−逾期天数），不做手工录入；支持记录催缴（方式/时间/结果/备注），催缴默认取会员联络员；缴费后欠费自动减少或消失。
- 欠费口径：按年度计算。

## 6. 财务管理（第一版）

范围：P04 收支记录 + P05 支出审批（OA 试点）+ 审批通过自动生成草稿流水（人工确认生效）。

- 支出审批分级（历史规则）：≤1000 元秘书长审，1000-5000 元会长审。
- 收支分类采用固定枚举：
  - 收入：会费收入、捐赠收入、项目收入、其他
  - 支出：活动经费、办公费用、项目支出、其他

## 7. 档案管理（第一版）

范围：A1 档号 + A2 著录 + A4 归档任务，按"只著录、先不扫描"起步。

- 档号规则：年度-类别-序号（如 2026-F-001）。
- 归档任务触发：自动触发（会员入会/审批通过/项目结项）与手动创建并存；超期未归档自动提醒。
