# 镇安县生态产业协会管理中台 1-4 级菜单设计

状态：历史菜单草案；已被 `PROJECT-OPERATING-MENU-RECOMMENDATION.md` 和 `PROJECT-MENU-PAGE-BASELINE.md` 覆盖（2026-10-18）

## 设计原则

- 一级是业务大类，二级是模块，三级是业务事项，四级是科目或操作视图。
- 最深只到四级，禁止增加第五级菜单。
- 六个业务大类全部属于首期范围，实施波次以页面基线为准；本历史草案中关于“首版裁剪”的表述不再适用。
- “工作台”是登录后的总览入口，不作为业务大类参与业务数据归属。
- 菜单权限由统一权限标准下发，菜单层级不等同于角色定义。
