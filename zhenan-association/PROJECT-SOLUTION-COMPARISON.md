# 镇安县生态产业协会管理中台方案比较

## 已确认决策

- 技术路线：全栈统一 TypeScript 单仓库。
- 架构形态：Next.js 一体化，服务端 API 与前端同一应用。
- 数据层：PostgreSQL + Drizzle ORM。
- 文件边界：网盘保存附件，应用保存档号、路径、版本和权限元数据。
- 交付方式：按已确认需求重新开发，不搬运旧工程。

## 决策依据

- 首版范围集中在会员、财务、档案三个中台模块，单团队维护优先于多服务拆分。
- 共享类型、权限模型和校验规则可避免前后端重复定义。
- OA 回流、草稿确认、年度账单和档号等事务逻辑需要服务端统一约束。
- 后续若出现独立移动端或外部系统复用需求，再从模块边界抽取独立服务。
- PostgreSQL 负责关系数据、唯一性和事务约束；Drizzle 保持 SQL 可控并共享 TypeScript 类型。
- 文件归档遵守正式网盘命名规范，首版不复制文件到应用数据库或对象存储。

## 阶段 4 待确认

- 首版信息架构与 1-4 级菜单落位。
- 数据库与文件存储边界。
- 轻立方/飞书登录、钉钉 OA 回流和与光工作中台的接口契约。
- 权限继承、补充账号有效期和草稿确认的状态模型。
