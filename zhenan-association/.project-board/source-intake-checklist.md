# 工程接管入库清单

将云端导出物放入项目目录后，按本清单逐项核验。不要放入密码、App Secret、Cookie、Authorization、访问令牌或真实业务数据。

## 必需材料

- [ ] 前端源码和静态资源
- [ ] 后端源码、云函数或平台逻辑导出
- [ ] 依赖清单与锁文件（如 `package.json`、`pnpm-lock.yaml`、`requirements.txt`）
- [ ] 构建、启动和部署配置
- [ ] 脱敏配置模板（只保留变量名，不含值）
- [ ] 数据库结构、迁移或初始化脚本；若使用平台内置表，导出表结构
- [ ] 测试代码、测试配置和测试说明
- [ ] 发布记录或版本标识

## 入库核验

- [ ] 记录压缩包来源、导出时间和文件哈希
- [ ] 列出真实目录树和运行时版本
- [ ] 找到启动、构建、迁移和测试命令
- [ ] 验证环境变量名称与用途，确认没有秘密值
- [ ] 检索租户、登录、组织架构、钉钉审批、飞书 SDK、网盘和模型调用
- [ ] 标记数据库/接口/权限校验的事实、推断和未知项
- [ ] 在隔离测试环境运行，不连接正式数据
