## 首版范围

### 会员管理

- M1 会费标准表：会员类型、任职身份、年度、金额、生效日期、表决记录附件。
- M2 入会申请：钉钉审批试点；通过后生成会员档案草稿，人工确认后生效。
- M5 会费收缴与欠费：年度应收账单、缴费核销、部分缴清/已缴清、实时欠费视图和催缴留痕。

### 财务管理

- P04 收支记录：固定收入/支出分类枚举。
- P05 支出审批：钉钉审批试点；通过后生成草稿流水，人工确认后生效。
- 金额边界：不把审批分级仅做成前端提示，服务端必须校验 `<=1000` 和 `1000-5000` 的规则；真实审批规则到工程导出后复核。

### 档案管理

- A1 档号：`年度-类别-序号`，示例 `2026-F-001`。
- A2 著录：只著录、先不扫描。
- A4 归档任务：会员入会、审批通过、项目结项自动触发，也支持手动创建；超期提醒。

## 关键业务不变量

- 应收账单按“会员单位 + 年度”唯一；已退出会员不计当年应收。
- 欠费金额为应收减实缴，并按年度计算；缴费核销后实时减少。
- OA 回流记录先是草稿，人工确认后才产生生效的会员档案或财务流水。
- 会费标准修改必须保留表决记录附件；五档合规风险和理事单位金额待书面确认。
- 补充账号有有效期，到期回收；长期协作者与临时访客的权限范围不同。
- 组织架构只同步与协会业务相关的部门和成员。
