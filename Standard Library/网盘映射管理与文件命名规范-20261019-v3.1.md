# 网盘映射管理与文件命名规范（2026-10-21 更新正式版）

- **版本**：v3.2
- **依据**：2026-10-18 更新版正式版及 2026-10-19 组织架构、应用架构调整
- **状态**：正式版

## 一、双租户根目录

| 租户 | 作用 | 规则 |
| --- | --- | --- |
| 轻立方 | 公司组织架构唯一主数据、轻立方侧人员入口、工作台、工具和大项目 | 与光组织节点映射到轻立方经营部，不承载望向山正式档案 |
| 与光 | 承载望向山、特产店、旅拍馆三家经营实体应用及相关人员 | 望向山正式档案归档在与光“望向山中台网盘”；组织节点映射到轻立方经营部 |

轻立方中台网盘为公司正式管理文件总归口；个人网盘仅存个人资料和灯塔知识库个人资料；企业历史档案库只进不出。两个租户共用同一文件编号序列。

双租户数据合并仅创始人可执行，禁止其他人员执行跨租户主数据合并；同一与光工作中台内的跨租户协作允许轻立方和与光人员按角色、项目、实体或事项授权参与，不等同于数据合并。

## 四、模块文件夹规则

与光工作中台的行政人事模块目录保留原 12 个模块：办公行政管理、后勤保障、资产管理、会务外联、流程建设、企业文化、人力资源规划与基础管理、招聘与配置管理、培训与发展管理、绩效管理、薪酬福利与考勤管理、员工关系管理。望向山正式档案不适用轻立方中台网盘目录，统一归档到与光 / 望向山中台网盘。

每个应用按已批准的菜单树映射业务目录。目录序号固定，不因上传顺序变化；没有文件的目录不创建。统一使用以下层级：

```text
应用根目录
└── 1.〔业务大类〕
    └── 1.〔模块工作〕
        └── 1.〔事项工作〕（如有）
            └── 1.〔科目工作〕（如有）
```

1 级为业务大类，2 级为模块工作，1 级和 2 级始终存在；3 级为事项工作，4 级为科目工作，按业务实际情况可有可无，不为补齐层级强行创建。只有 2 级页面时，文件直接归档到 2 级目录；有 3 级但没有 4 级时，文件归档到 3 级目录。业务目录名称和序号以应用的菜单实施基线为准。

应用根目录名称使用正式网盘映射中的应用名称。以镇安县生态产业协会管理中台为例，正式映射仍为：`中台网盘 / 3. 业务部 / 1. 项目部 / 2. 镇安生态产业协会管理中台`；其目录内部按“业务大类 → 模块工作 → 事项工作 → 科目工作”展开。

不使用 `待归档`、`已归档` 作为业务流程目录。文件一旦通过来源校验和命名处理，即按页面菜单上下文归入目标业务目录；系统内部可以保留处理状态和审计记录，但不得以这两个状态目录替代业务目录。

## 五、管理文件来源和发布

管理文件类型包括：**管理制度、标准说明、纸质模板、电子模板**及业务页面产生的业务文件。文件来源有两类：**OA 附件同步归档**和**部分业务页面上传**。

1. OA 文件必须在 OA 侧规范命名并作为审批附件提交；中台校验名称、类型、版本号和附件完整性，原则上不破坏 OA 正式文件名、版本事实和来源凭证。
2. OA 审批通过后，附件按 OA 业务归属同步到对应菜单目录，默认成为该主题的当前发布版本；同步保存 OA 单据号、来源文件 ID、审批版本和同步时间。
3. 业务页面上传时，员工不选择归档目录。系统使用当前页面绑定的 1-4 级菜单上下文确定目标目录，并在服务端完成归档和命名校验。
4. 对可解析的文本、表格和文档，系统可以扫描文件名、扩展名及内容，辅助识别文件主题、版本和是否属于同一迭代文件；扫描件、不可解析文件、主题或版本无法确定时必须进入人工确认，不得静默改名、合并、覆盖或移动。
5. 发现命名、版本、附件或归属不符合规范时，工作台标记异常并要求补正；不得把文件放入 `待归档` 或 `已归档` 目录冒充归档完成。
6. 只有创始人、模块负责人或被授权的页面操作人可以确认发布或上传；下载权限按现有权限规范点对点授权并记录日志。OA 正式文件的审批权仍归 OA。
7. 网盘映射规则、应用架构规范和组织架构规范同步修订、同步审核、同步发布；每次发布记录版本、确认人、执行人和生效时间。

## 六、文件命名

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 文件夹 | `序号.名称`，编号固定不复用 | `1. 行政人事部` |
| 管理制度 | `制度名称-v主版本.次版本-生效日期` | `费用报销管理制度-v2.0-20261019` |
| 标准说明 | `事项名称-标准说明-v主版本.次版本-日期` | `入职办理-标准说明-v1.1-20261019` |
| 纸质模板 | `事项名称-纸质模板-v主版本.次版本-日期` | `用印申请-纸质模板-v1.0-20261019` |
| 电子模板 | `事项名称-电子模板-v主版本.次版本-日期` | `薪资核对-电子模板-v1.2-20261019` |
| 员工档案 | `序号.工号-姓名-文件类型-日期` | `1.YG001-员工入职审批-20261019` |
| 页面导出 | `事项名称-v主版本.次版本-日期` | `组织架构图-v1.0-20261019` |
| 业务页面上传 | `文件主题-YYYYMMDDHHmmss-v主版本.次版本` | `会员缴费登记-20261021143000-v1.0.xlsx` |
| 历史资料目录 | `文件主题历史资料` | `会员管理制度历史资料` |
| 旧版文件 | 原规范文件名后追加 `-旧版` | `会员管理制度-v1.0-20261021-旧版.docx` |

文件名不得带公司全称；主体简称统一使用“与光”，不得使用“宇光/雨光”等异名。版本号采用 `v主版本.次版本`，正式发布必须有生效日期。

业务页面上传的文件由系统在服务端生成或校验规范名称，时间取归档处理时间。无法可靠识别主题、版本或文件对象时，保留原文件并进入人工确认，不猜测内容。

## 七、历史版本与审计

- 当前生效文件和历史文件均保留原始 OA 单据号（如有）、审批版本、来源、发布人、确认人、同步时间和网盘链接。
- 对同一主题的迭代型文件（例如 `会员管理制度-v1`、`会员管理制度-v2`），当前目录只保留最新版；新版本进入当前目录后，旧版自动移动到当前目录下按主题建立的 `〔文件主题〕历史资料` 目录，原文件名末尾追加 `-旧版`。历史资料只读保留，不覆盖、不物理删除。
- 不同内容的独立文件（例如 `工资表-8月`、`工资表-9月` 或不同企业营业执照）全部保留在当前业务目录，不互相移动到历史资料目录；按文件主题、对象和日期命名即可。
- 历史文件不可覆盖、不可物理删除；撤回或废止时标记状态并保留审计记录。
- 中台保存文件元数据、校验结果、定位索引和下载日志；正式文件以飞书网盘文件为准。
- OA 附件原始内容纳入全量检索和问题分析；临时扫描副本完成后删除。

## 八、菜单层级映射规则

| 层级 | 对应 | 点击行为 |
| --- | --- | --- |
| 1 级 | 业务大类 | 目录格式为 `序号.名称`；只有大类名字，点击只折叠/展开 2 级菜单 |
| 2 级 | 模块工作 | 目录格式为 `序号.名称`；有下级时默认进入第一个 3 级，或其第一个 4 级；没有下级时进入独立 2 级页面 |
| 3 级 | 事项工作 | 可选；目录格式为 `序号.名称`，进入事项页面，承载列表、状态、筛选和 4 级入口 |
| 4 级 | 科目工作 | 可选；目录格式为 `序号.名称`，进入最小操作页面，禁止 5 级 |

默认落地优先级为：第一个 3 级下的第一个 4 级 → 第一个 3 级 → 独立 2 级页面。已验证的单一工作页不为套层级强行拆分。
