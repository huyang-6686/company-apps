# 与光任务功能配置启动清单

- **版本**：v1.0（2026-10-20）
- **状态**：启动执行清单
- **依据**：《任务发布与管理规范-20261020正式版》《任务接口合同-20261020正式版》

## 一、与光工作中台配置

- [ ] 在工作台下启用“任务看板”模块。
- [ ] 配置“我发布的、我负责的、与我协作的、发布任务、任务统计”页面。
- [ ] 配置三类任务：日常任务、经营任务、项目任务。
- [ ] 配置应用必选、模块可选、应用通用任务显示规则。
- [ ] 配置应用授权和模块授权过滤，禁止无权限人员展示和选择。
- [ ] 配置角色发布权限开关；默认禁止观察人和只读人员发布。
- [ ] 配置向下发布和同级协作，关闭向上发布和下属辐射。
- [ ] 配置协作部门/协作人选填字段及协作要求。
- [ ] 配置待接收、进行中、待验收、已完成、已驳回、已逾期、已取消状态。
- [ ] 配置发布、临期、超期、修改、提交、驳回、验收、取消和自动转派通知。
- [ ] 配置接收人离职/调岗自动转派到部门负责人的规则。
- [ ] 配置详细统计报表和数据权限。
- [ ] 配置任务附件飞书网盘映射、文件权限和下载日志。

## 二、应用接入准备

每个应用按接口合同提交：

- 应用 ID、模块 ID 和负责人；
- 应用任务看板路径和回调地址；
- 应用可接收的任务类型和模块范围；
- 应用人员授权映射；
- 联调负责人和测试账号；
- 事件签名公钥或密钥配置；
- 网盘映射目录确认记录。

## 三、联调顺序

1. 与光下发测试任务，验证应用看板展示和通知。
2. 应用回传接收确认、反馈、完成提交和附件索引。
3. 与光执行验收通过、驳回、修改和取消，验证应用状态同步。
4. 模拟截止、逾期、离职/调岗，验证通知、自动转派和历史留痕。
5. 验证普通员工、部门负责人、应用负责人、项目成员、实体负责人和实体员工的可见范围。
6. 执行重复事件、版本冲突、越权访问和断线补偿测试。

## 四、上线门槛

接口合同测试通过、权限矩阵核验通过、网盘映射核验通过、审计日志核验通过后，应用负责人和与光负责人共同确认接入。未完成联调的应用不得开启生产任务发布。
